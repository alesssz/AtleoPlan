# Security

AtleoPlan is a personal project in development. It is not deployed, so there is no live service holding anyone's data.

## Reporting a problem

If you find a security problem in this code, such as a way to read another user's data or a secret committed by mistake, please report it **privately**: on this repository's **Security** tab, choose **Report a vulnerability**. Please do not open a public issue for it.

You will get an answer there. Thank you.
